# 前端 UI 优化设计规格

> 日期: 2026-07-07 | 状态: 待实现

## 概述

对 gocron v2.0 前端 (Vue 3 + Element Plus) 进行三项 UI 优化：
1. 统一各页面展示区域宽度
2. 优化任务列表展开行信息展示
3. 实现移动端响应式适配

## 一、页面宽度统一

### 问题
当前各页面最大宽度不一致：Dashboard 1400px、列表页 1200px、编辑页 960px，页面切换时有视觉跳跃。

### 方案
按页面类型分级统一：

| 页面类型 | 统一宽度 | 涉及页面 |
|---------|---------|---------|
| 列表/表格页 | `max-width: 1200px` | Dashboard(任务列表)、节点列表、用户列表、日志列表、登录日志 |
| 编辑/表单页 | `max-width: 960px` | 任务编辑、节点编辑、用户编辑、修改密码 |
| 通知配置页 | `max-width: 1200px` | 邮件/飞书/企微/Webhook 通知 |
| 登录/安装页 | 独立不变 | 卡片居中布局，各自已有固定宽度 |

### 实现
- 创建全局 CSS 类 `.page-container`（1200px）和 `.page-form`（960px）
- 各页面统一使用这些类替换各自的内联 `max-width` 值
- 在 `global.css` 中添加宽度工具类

## 二、任务列表展开行优化

### 问题
当前展开行使用基础 `el-descriptions`，纯文字堆砌，缺乏视觉层次，信息扫描效率低。

### 方案
替换为**卡片式信息网格**：每个字段一张独立卡片，图标 + 标签 + 值。

### 展示字段
- 创建时间、任务类型、超时设置、重试次数
- Cron 表达式、执行命令（截断预览）
- 备注（跨多列）
- 子任务列表（如有）

### 实现
- 新建 `TaskDetail.vue` 组件，替代展开行中的 `el-descriptions`
- 使用 CSS Grid 布局：`grid-template-columns: repeat(auto-fill, minmax(200px, 1fr))`
- 备注字段 `grid-column: span 2`
- 卡片背景浅灰（`var(--color-background)`），圆角 8px，内边距 12px
- 标签小号灰色，值加粗深色

## 三、移动端响应式适配

### 问题
项目零媒体查询，导航栏无折叠、表格无横向滚动处理、统计卡片在窄屏挤压变形。

### 方案：全面响应式，3 个断点

| 断点 | 宽度范围 | 适配行为 |
|------|---------|---------|
| 桌面 | ≥ 1024px | 现状布局，导航栏水平展开 |
| 平板 | 768px – 1023px | 统计卡片 2×2 网格；表格横向滚动；导航栏紧凑 |
| 手机 | < 768px | 汉堡菜单侧滑；统计卡片 2×2；表格横向滚动；搜索栏纵向堆叠；操作按钮折叠 |

### 各组件适配详情

**1. 导航栏 (AppHeader)**
- 手机端：Logo + 汉堡图标按钮，点击打开 `el-drawer` 侧滑菜单
- 平板端：保留水平导航但缩小间距和字号
- 用户下拉菜单保持不变

**2. 统计卡片 (Dashboard stats-row)**
- ≥1024px: `repeat(4, 1fr)` 四列
- <1024px: `repeat(2, 1fr)` 两列
- <768px: `repeat(2, 1fr)` 两列，字号缩小

**3. 表格 (所有页面)**
- 所有 `el-table` 统一使用 `scroll-x` 或容器 `overflow-x: auto`
- 操作列 `fixed="right"` 保持在可视区域
- 手机端操作按钮折叠为 `el-dropdown`（"更多"按钮）

**4. 搜索/工具栏**
- <768px: `flex-direction: column`，输入框 `width: 100%`
- 搜索条件纵向堆叠，按钮靠右

**5. 弹窗 (Dialog)**
- <768px: `width: 90vw`，避免横向溢出
- 全屏模式用于复杂表单（如任务编辑）

**6. 表单 (Edit 页)**
- <768px: Element Plus 的 `el-col` 的 `:span` 全部改为 24（占满行）
- 使用 `:xs="24" :sm="12" :md="8"` 响应式 span

### 实现方式
- 在 `global.css` 中添加断点变量和媒体查询
- 各组件 `.vue` 文件的 `<style scoped>` 中添加对应断点的样式覆盖
- 导航栏的汉堡菜单逻辑写在 `AppHeader.vue` `<script setup>` 中

## 技术约束

- 不引入新的依赖库，仅使用项目已有的 Element Plus 组件
- 样式使用 CSS 变量（`var(--color-*)`）保持与现有设计系统一致
- 图标使用 `@element-plus/icons-vue`
- 遵循 Vue 3 Composition API (`<script setup>`) + 单文件组件模式

## 验证

- `npm run build` 构建成功
- 桌面端（≥1024px）：所有页面宽度统一，展开行卡片式展示
- 平板端（768px-1023px）：统计 2×2，导航正常，表格可滚动
- 手机端（375px-768px）：汉堡菜单，表格滚动，工具栏堆叠
